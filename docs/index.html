PPICKUP
A plugin for Claude Code

Claude never loses its place.

Pickup keeps one plain-English page about your project, called PICKUP.md. Claude reads it back after compaction and at the start of every new chat. You never have to remember to save.

The problem

Claude's desk fills up.

Everything in your chat sits on Claude's desk. In a long session the desk gets full, so Claude Code clears it and leaves a short note. That's called compaction. The note is short, so details get lost. A new chat has your CLAUDE.md, auto memory and /resume, but none of them reliably keeps where the project stands.

Without Pickup

Claude starts guessing.

  • ✕Decisions you agreed on can get lost.
  • ✕Fixes that already failed can get tried again.
  • ✕Your exact words can turn into a vague summary.
  • ✕A new chat may not know what's done or what's next.
With Pickup

The notebook goes back on the desk.

  • ✓The plan, decisions and their reasons are written down.
  • ✓Your latest requests are kept word for word.
  • ✓After compaction, Claude reads the notebook again.
  • ✓A new chat opens with where you left off.
How it works

Install once. Work as usual.

Open your project folder

Start a chat in the folder where your project lives. Each folder gets its own notebook.

Do some real work

After a few edits, PICKUP.md appears in the folder. Claude keeps it current as you go.

The desk gets cleared

Compaction happens, or you close the chat and come back tomorrow.

Claude picks up

Pickup loads the notebook, and Claude opens with one line on where things stand.

Three commands

Or just say it.

You rarely need these. They're there when you want to check in or start fresh. Plain words work too.

/pickup:save

Updates the notebook right now and tells you the next step.

or say: "save progress"

/pickup:status

Tells you in plain English where the project stands. It never changes the file.

or say: "where are we?"

/pickup:handoff

Gets the notebook fully ready for a fresh start. Then open a new chat in the same folder, or type /clear.

or say: "let's start fresh"

Questions

Good to know.

What does Pickup write into my project?

Only one file: PICKUP.md. Its raw activity log lives in the plugin's private data folder, never in your project.

Does it send my work anywhere?

No. Pickup itself makes no network calls, and there are no accounts and no cloud. Its log stays on your computer. The notebook is read into your Claude chat, the same way Claude reads any other file in your project.

Do I need Node or Python?

No. It uses plain sh and awk, so it runs on Mac and Linux. On Windows it needs Git for Windows (free).

Can I edit the notebook myself?

Yes. If you edit PICKUP.md by hand, Claude follows your version. Leave the block between the pickup:facts markers alone, because Pickup fills that part.

How do I turn it off for one project?

Create an empty file named .pickup-off in that project's folder. Pickup stays quiet there.

Can I change how often it saves?

Yes. Set PICKUP_SAVE_AFTER_EDITS to the number of edits between reminders. The default is 6, and 0 turns the reminders off. Add it to your Claude Code settings file (~/.claude/settings.json) under "env".
